# OpenSource SW / Git-practice

## Student score analysis

This project contains sample student score data and a script that summarizes it.

### Run

```powershell
python analyze_scores.py
```

The script reads `data/students.csv` and prints the total number of students,
average, highest and lowest scores, the number of students scoring at least 80,
and department averages.

The sample output is saved in [results/summary.txt](results/summary.txt).
